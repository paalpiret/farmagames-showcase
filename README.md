# clinicalgames

Website for clinicalgames.fi — learning games and digital tools for nursing education, by Piret Paal.

## Structure

- `index.html` — landing page layout and styling
- `content.js` — all landing-page text, English and Finnish (edit wording here)
- `myday/`, `farmarush/`, `medichain/`, `medilink/` — one folder per game, each with its own `index.html`
- `images/` — the promo images used on the landing page
- `DESIGN.md` — design and content decisions; `TECH-NOTES.md` — how the site works, in plain language

## Live site

https://clinicalgames.fi — served via GitHub Pages from this branch (`claude/farmagames-landing-page-pmzh69`). Every push to this branch goes live.
