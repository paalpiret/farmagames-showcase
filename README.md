# FarmaGames

Showcase site for nursing education game prototypes.

## Structure

- `index.html` — landing page (about section + game links)
- `myday/`, `farmarush/`, `medichain/`, `medilink/` — one folder per game; drop each game's HTML (and any assets) into its folder as `index.html` to replace the placeholder page

## Live site

Served via GitHub Pages from this branch.
